Reference · isafuianish-dev/config_windows

Dotfiles for a fresh Windows machine

Personal Windows setup: install scripts, shell config, and app settings. One command takes a clean Windows machine to a working PowerShell shell.

irm https://raw.githubusercontent.com/isafuianish-dev/config_windows/main/install.ps1 | iex

Installs git python node uv jq ripgrep fzf bat eza wget gh via winget, plus vscodium and the Meslo Nerd Font (fetched directly - not published on winget). winget itself ships with Windows 11, and tree ships with Windows already, so neither needs installing.

Optional: the bootstrap asks whether to install Temurin OpenJDK 21 (other/java.ps1) via winget (EclipseAdoptium.Temurin.21.JDK). Once installed, env.ps1 sets JAVA_HOME and adds its bin to PATH automatically. Skipped it? Run .\other\java.ps1 later and restart your terminal.

Optional: the bootstrap also asks whether to set up the Android SDK (other/android.ps1). There's no winget package for the command line tools alone, so this fetches Google's repository manifest to resolve the current Windows cmdline-tools archive into %LOCALAPPDATA%\Android\Sdk, then uses the android CLI (which superseded the now-deprecated sdkmanager/avdmanager) to install platform-tools and a platform/build-tools at API 34, plus a medium_phone AVD. env.ps1 sets ANDROID_HOME/ANDROID_SDK_ROOT and PATH automatically, and android.ps1 (functions below) is only loaded once the SDK exists. Skipped it? Run .\other\android.ps1 later and restart your terminal.

Secrets directory: env.ps1 creates %USERPROFILE%\Developer\secrets if needed and exports it as SECRET_DIR — used by the Android signing functions below, and available for anything else that needs a place to keep local secrets.

GitHub tokens: the bootstrap opens GitHub's token form (name and permissions pre-filled) once for a read-only token and once for a read/write token, and asks you to paste each one. They're saved in %USERPROFILE%\Developer\secrets\github, and env.ps1 exports them as GITHUB_PAT_READ and GITHUB_PAT_READWRITE in every PowerShell session. Skipped one? Run .\other\github_pat.ps1 later. To replace a token, delete its file and re-run.

Coming from the old cmd.exe version? Re-running the bootstrap removes the old cmd.exe AutoRun hook and wires PowerShell instead. The repo now lives in Developer\projects\configuration\config_windows; an older clone in Developer\projects\config_windows is unused and can be deleted.

💡 After bootstrapping, run gh auth login once — without it, the gh-based aliases and functions below (ghpr, ghrv, gitbornr, …) fail with an auth error.

Layout

Every script is idempotent — safe to re-run after pulling changes.

.
├── install.ps1                 # entry point for a fresh machine
├── ps_profile/
│   ├── profile.ps1             # dot-sourced by your PowerShell profile, loads every module below
│   └── module/
│       ├── env.ps1             # GITHUB_PAT_READ / GITHUB_PAT_READWRITE / SECRET_DIR / JAVA_HOME / ANDROID_HOME
│       ├── alias.ps1           # shortcuts, grouped by the command they wrap
│       ├── function.ps1        # shell functions
│       ├── android.ps1         # Android functions (create_device, create_release_apk, ...), only when the SDK is installed
│       └── prompt.ps1          # powerline-style prompt with live git status
├── git_setup/
│   ├── git_config.ps1          # global git identity + settings
│   ├── git_alias.ps1           # git born / git kill / git addremote / ... aliases
│   └── gitignore_global        # git's core.excludesfile, applies to all repos
├── app_config/
│   └── vscodium/settings.json # copied (or symlinked) into VSCodium's User dir by install.ps1
└── other/
    ├── winget.ps1              # winget + packages
    ├── java.ps1                # optional: Temurin OpenJDK 21 (bootstrap asks first)
    ├── android.ps1             # optional: Android SDK cmdline-tools + AVD emulator (bootstrap asks first)
    ├── github_pat.ps1          # prompts for GitHub tokens, saves them to ~/Developer/secrets/github
    └── ssh.ps1                 # SSH key generation (skips if one already exists)
🛈 A PowerShell alias can't carry arguments, so each shortcut in alias.ps1 is a small function that passes extra arguments through, and everything is global: so reload works from inside a function. function.ps1 is self-contained: the git born / git kill / … aliases run it through powershell -NoProfile. ni is a built-in alias for New-Item; the profile removes it so ni means npm install.
🛈 Differences from macOS. Everything here has a macOS twin with the same name; what's left is platform-specific. winget replaces Homebrew, so there's no bc alias and no bash/htop/tree package. There are no grep/egrep/fgrep color aliases, py, pip, or - (Windows already has py and pip, and cd - is built into PowerShell 7). The optional openjdk@21 install and JAVA_HOME setup are macOS-only for now. System aliases like showfiles and restartdock drive Explorer and the registry instead of Finder and Dock.

Functions

Defined in function.ps1. Same set, usage, and messages as macOS.

mkcd <dir>

Create the directory (and parents), then cd into it.

up [n]

cd up n directories, default 1.

extract <file>

Extract almost any archive type based on its extension (.zip/.tar* via Windows' built-in tar; .gz natively; .7z/.rar/.bz2 via 7z/unrar if installed).

backup <path>

Copy a file/dir alongside itself with a timestamp suffix.

port <n>

Show what's listening on TCP port n.

killport <n>

Kill whatever's listening on TCP port n.

serve [port]

Serve the current directory over HTTP, default 8000.

pj [file]

Pretty-print JSON from a file or stdin.

myip

Print this machine's public IP address.

git-clean-branches

Delete local branches already merged into the current one (never main/master).

note ["text"]

Append a timestamped line to %USERPROFILE%\notes.md, or print it with no args.

caffeinate

Keep this machine and its display awake until you Ctrl+C.

gitborn

For a plain, non-git directory: git inits and makes a first commit. No remote. Refuses if already inside a git repo.

gitbornr

For a plain, non-git directory: asks private/public, then git inits, commits, creates a GitHub repo named after the folder, and pushes. If public, also asks whether to enable GitHub Pages for it. Refuses if already inside a git repo.

gitaddremote

For a repo with no remote yet: asks private/public, creates a GitHub repo named after the root folder, and pushes. If public, also asks whether to enable GitHub Pages for it. Refuses if origin already exists.

gitremoveremote Destructive

Deletes the linked GitHub repo and removes the local origin remote. Refuses if there's no local repo or no remote.

gitenablepage

Enables GitHub Pages for the current repo, serving from the current branch's root. Refuses if there's no local repo, no remote, the repo is private, or Pages is already enabled.

gitdisablepage

Disables GitHub Pages for the current repo. Refuses if there's no local repo, no remote, or Pages isn't enabled.

gitkill Destructive

Deletes the GitHub repo, if one's linked, and wipes local git history. Asks for yes first.

gitcomparelocal

Clones main fresh from the GitHub repo named after the current folder into a temp folder and compares it with the local folder, printing an [A]/[D]/[M] report of added/deleted/changed files. Works even if the local folder isn't a git repo.

gitoverridelocal Destructive

Deletes everything in the current folder, including .git, and replaces it with a fresh clone of the GitHub repo named after the folder. Refuses if no such repo exists. Asks for yes first.

Android functions

Defined in android.ps1, only loaded when the Android SDK is installed. Ported from macOS's android.sh so both platforms have the same commands, prompts, and messages. They wrap the android CLI, adb, and Gradle. create_signing_key, create_release_apk, and run_release_apk expect a standard Gradle project with an :app module and a release signingConfig that reads KEYSTORE_PATH/KEYSTORE_PASSWORD/KEY_ALIAS/KEY_PASSWORD from the environment. One platform difference: signing credentials are read from a dot-sourced credentials.ps1 ($env:KEYSTORE_PATH = '...' lines), not macOS's bash-style credentials.env, since PowerShell has no source for .env files. Run android_help for a colorized cheat sheet of everything below, printed straight to the terminal.

android_help

Print every function below with a one-line description, colorized, plus a few things worth remembering.

list_device

List every AVD with its current status (running/stopped).

start_device

Ask which stopped AVD to start, launch it in the background, and wait (up to 2 minutes) for adb to see it.

stop_device

Ask which running AVD to stop, then stop it (android emulator stop).

create_device

Create a new AVD, asking which device profile to use (android emulator create).

delete_device Destructive

Ask which AVD to delete, confirm with yes, then delete it.

clone_device

Ask which AVD to clone and its new name, then duplicate its files (there's no native android emulator clone). Refuses if the source AVD is currently running.

wipe_device

Ask which AVD to wipe, then clear its user data for a fresh start without deleting the device. Refuses if it's currently running.

create_signing_key

Run from a project root: generates a release signing key and $env:SECRET_DIR\<project dir name>\credentials.ps1. Refuses if a key already exists there.

create_debug_apk

Run from a project root: .\gradlew.bat assembleDebug, then prints the built APK's path.

create_release_apk [versionName] [versionCode]

Run from a project root: dot-sources $env:SECRET_DIR\<project dir name>\credentials.ps1, builds :app:assembleRelease, verifies with apksigner that it's not debug-signed, and copies it to dist\<name>_v<version>.apk (older versions there are left alone). Refuses if create_signing_key hasn't been run yet.

run_debug_apk

Installs and launches the most recently built debug APK on a running device/emulator. Refuses if none are running; asks which one if several are.

run_release_apk

Same as run_debug_apk, but with the most recently built release APK from dist\.

plain command shortcuts

git unstage

Runs git reset HEAD --. Unstage a file without losing its changes.

git last

Runs git log -1 HEAD. Show the last commit.

git amend

Runs git commit --amend --no-edit. Amend the last commit without changing its message.

git undo

Runs git reset --soft HEAD~1. Undo the last commit, keeping its changes staged.

git graph

Runs git log --oneline --graph --decorate --all. Compact graph log of every branch.

git contributors

Runs git shortlog -sn. List contributors ranked by commit count.

git aliases

Runs git config --get-regexp ^alias\.. List every configured git alias.
